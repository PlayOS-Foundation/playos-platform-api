# Getting Started — Build Your First PlayOS Game

This guide walks through the minimal PlayOS game in
[`examples/minimal_game.c`](../examples/minimal_game.c). It uses only the
frozen public API (`PLAYOS_API_VERSION 1`).

## Prerequisites

- A host with a C compiler and `pkg-config`.
- The PlayOS SDK headers (Sprint 14) or the `playos-platform-api` checkout.
- For on-device runs: a PlayOS dev image (SSH) or a release image.

## 1. Include the API

```c
#include <playos.h>
```

`playos.h` pulls in all eight API groups: audio, display, input, lifecycle,
logging, power, storage, and system.

## 2. Lifecycle — handle it every frame

PlayOS is a console: the system can background, suspend, or terminate your
game at any time.

```c
PlayOSLifecycleEvent ev;
if (playos_lifecycle_poll(&ev) == 1) {
    switch (ev) {
    case PLAYOS_LIFECYCLE_FOREGROUND:  /* resume rendering */
    case PLAYOS_LIFECYCLE_BACKGROUND:  /* pause, mute, yield CPU */
    case PLAYOS_LIFECYCLE_SUSPEND:     /* save state immediately */
    case PLAYOS_LIFECYCLE_RESUME:      /* restore state */
    case PLAYOS_LIFECYCLE_TERMINATE:   /* save + exit(0) within 2s */
    }
}
```

## 3. Read the controller

```c
PlayOSControllerState state;
if (playos_input_get_controller_state(&state) == 0) {
    if (playos_input_button_down(&state, PLAYOS_BUTTON_SOUTH)) {
        /* A button */
    }
    float lx = state.axes[PLAYOS_AXIS_LEFT_X];
    float ly = state.axes[PLAYOS_AXIS_LEFT_Y];
}
```

Buttons are a bitmask (`PLAYOS_BUTTON_*`), axes are floats
(`PLAYOS_AXIS_LEFT_X` … `PLAYOS_AXIS_RIGHT_TRIGGER`).

## 4. Save progress safely

```c
char path[512];
snprintf(path, sizeof(path), "%s/save.bin", playos_storage_get_saves_path());
playos_storage_atomic_write(path, data, len);
```

`playos_storage_atomic_write` is crash-safe: the old file or the complete new
file is always present.

## 5. Log

```c
PLAYOS_LOG_I("game", "starting on %s", playos_system_device_model());
```

Logs go to the per-game session log on the device.

## 6. Build

```sh
# Device build (musl, via pkg-config when the SDK provides playos.pc):
gcc $(pkg-config --cflags --libs playos) minimal_game.c -o bin/game

# Desktop iteration (Sprint 15 shim):
gcc -I../include minimal_game.c -o game -lplayos -lraylib
```

## 7. Ship

A PlayOS game is:

```text
bin/game
manifest.json
assets/
```

`manifest.json` declares the game id, entry point, and permissions. See the
game-developer guide in `playos-spec/docs/` for the full manifest schema.
